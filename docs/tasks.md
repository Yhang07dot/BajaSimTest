# 题目要求

## 任务范围

完成两项可独立实现和评分的任务：

1. 根据传感器观测检测规定的三维目标障碍。
2. 估计车辆前方道路左右边线的几何位置。

输入为16线点云，可选使用前视相机、CameraInfo和TF。车辆行驶与控制由平台负责。停车位不属于场景；坑、坡、凸起作为测试条件保留，不要求独立提交路面区域识别结果；不要求二维像素框。

## 任务一：三维目标检测

| 项目 | 要求 |
|---|---|
| 正目标 | 随机箱体、桶、目标锥桶、人形，以及固定交通设施 |
| 背景 | 路边蓝红边界锥桶、地面和没有目标的空间 |
| 输出 | Detection3DArray：中心、朝向、完整尺寸、置信度、类别 |
| 主要成绩 | 障碍检出F1×100；另报定位和尺寸误差 |
| 分类 | 单独报告，纯几何算法允许输出unknown_obstacle |

随机目标锥桶是正目标，沿道路连续排列的边界锥桶是背景。把边界锥桶报成障碍计误检；漏掉有效目标计漏检；重复框不能重复得分。不需要输出真值ID。

当前主要检测成绩衡量检出和中心定位，框朝向和IoU尚未计入匹配，因此不能仅用F1宣称完整三维框质量达标。

## 任务二：道路边线估计

| 项目 | 要求 |
|---|---|
| 目标 | 道路左右设计边界的水平几何位置 |
| 边界定义 | 沿边界物标底面中心形成的道路边缘曲线 |
| 输出 | RoadBoundaryArray：左右属性、置信度、有序三维点列 |
| 成绩 | 同侧几何precision、recall、F1×100与水平误差 |

不要求逐个检测锥桶，也不评价锥桶数量和颜色识别。算法内部可采用多项式、样条或其他方法，统一输出折线。未知区间保留空隙，用多段表达，不强行连接；重合线段应合并，左右属性不能颠倒。

## 通用要求

- 原始输入的采集时间戳；三维结果统一到采集时刻的base_link，单位米。
- 每个输入参考帧发布一条对应任务结果，没有检测时也发布空数组。
- 算法不得读取/订阅真值、场景物体清单，或硬编码seed对应的答案；可使用评测视图检查效果。
- 不修改车辆控制、传感器、真值或评分器以提高成绩。只在自己的算法包中实现和调参。
- 启动算法前source工作空间，设置use_sim_time=true；输出格式见 [interfaces.md](interfaces.md)。

## 提交内容

1. 放在src/algorithms/<包名>的ROS 2算法包，含依赖与安装规则。
2. 安装后的launch/perception.launch.py，以及需要的参数文件。
3. 能复现的运行命令，注明seed、车速和参数版本。
4. 分项评分报告，以及至少说明典型误检、漏检和边线失败情况。

模板仅发布空数组，用于接口验证，不包含识别算法。不得用复制真值替代实现。

评分配置应在评测前统一，同一比较中保持场景、seed、速度和门限一致。仓库不预设通过分数，也不预设两题权重；规则与适用范围见 [evaluation.md](evaluation.md)。
