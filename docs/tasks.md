# 本轮题目定义 v0.2

本轮只有两个任务：三维目标检测、道路左右边线几何估计。停车位已删除；独立二维检测和特殊路面区域评分不属于本轮。坑/坡/凸起仍保留在场景中，作为观测与车身姿态的测试条件；相机仍可用于辅助三维算法。

## 题目一：三维目标检测

- 输入：点云，可选前视图像、CameraInfo和TF；不能读取场景真值或seed物体坐标。
- 对象：场景随机箱体、桶、目标锥桶、人形及交通设施。路边蓝/红边界锥桶是背景，不是障碍目标。
- 输出：`/perception/objects_3d`，`vision_msgs/Detection3DArray`；框中心、朝向、尺寸、置信度、类别，原采集时间戳、base_link。
- 主要成绩：检出F1×100，另报告定位和尺寸误差；语义分类作为独立成绩，几何示范算法可输出unknown_obstacle。
- 误检：把边界锥桶、地面或空处报成障碍，均计FP；漏掉有效真目标计FN；重复框只有一个可能成为TP。
- 不要求算法输出真值ID。空结果也需发布，不能通过不发消息逃避漏检。

## 题目二：道路边线几何估计

- 输入：点云，可选相机和TF。
- 真值：道路设计的左右几何边界；锥桶只是形成可观测边界的物标。
- 输出：`/perception/road_boundaries`，`baja_sim_interfaces/RoadBoundaryArray`；左右属性、置信度、按曲线顺序排列的三维点、原采集时间戳、base_link。
- 不评价逐个锥桶的数量、颜色分类或识别率。
- 在规定前方区域内比较同侧边线的水平几何位置，统一按弧长重采样；覆盖率衡量漏画，精确率衡量画错/多画，F1×100为边线分。
- 多段用多条折线表达，不跨未知区域连线；左右颠倒按错误几何处理，空输出记零覆盖。
