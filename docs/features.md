## 需要讨论的决定

1. **交付优先级**：原始需求包含二维目标与特殊路面识别，它们还没完成。建议先接入第一份真实三维算法确认接口，再补路面区域与相机评分，不能把这些原始任务默认为已交付。
2. **评分标准**：当前中心距离≤1m匹配、置信度≥0.25、前方30m ROI。是否改为按类别/尺寸设门限或采用IoU/AP，需要与算法团队确定。
3. **可见性和漏检**：当前真值框内至少1个激光返回点就参与召回分母。需要明确最少点数、遮挡等级和极小目标成绩；融合算法还需独立相机可见性定义。
4. **目标多样性**：是否随机灯色、限速数字、背景、光照、模型外观和遮挡，需要确定测试矩阵和seed集合。
5. **真实性已暂缓**：按用户最新要求，不安排反射率、扫描畸变、相机噪声、照片级模型或悬架工作，保留当前简化模型；这些不是近期交付前提。
6. **速度和重复性操作**：现在通过启动参数/YAML调速。是否需要运行中调速、暂停、重置、批量测试，以及使用固定录制输入比较算法，后续再确定。

DEBUG只是隐藏真值显示，后台评分仍使用真值，ROS话题不做访问控制。没有算法时显示等待；空模板零召回符合预期。实际验证见 [acceptance.md](acceptance.md)，调速和鼠标操作见 [controls.md](controls.md)。

后续独立会话的任务拆分、依赖和验收要求见 [handoff.md](handoff.md)。边界锥桶纳入检测还是ignore，需先确认，当前代码没有自动忽略它们。
