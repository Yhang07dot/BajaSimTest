# 当前工作与示范算法安排

## 已确定范围

- 本轮只做三维目标检测和左右道路边线几何估计，定义见 [tasks.md](tasks.md)。
- 停车位模型、真值、任务已删除，不再安排停车或车位识别。
- 边界锥桶不是障碍目标；把它们报为障碍计FP并降低三维分。边线只按几何准确率与覆盖率评价，不要求逐个锥桶识别。
- 相机继续提供图像，但独立二维像素框任务不在本轮；特殊路面保留为场景条件，不增加区域识别评分。
- 真实性增强暂缓。

## 正确的实施顺序

1. **当前会话**：完善两道题的定义、输出消息、真值、误检/漏检/边线评分、可复算案例、评分查看和文档。这一步不是直接把未完成任务全部交给其他会话。
2. **下一阶段先做示范算法**：真实订阅传感器，估计左右边线，提取三维目标，跑通显示和评分。示范算法用于说明如何做题；允许分数不高，必须如实报告。
3. **示范跑通后再交接替换**：其他会话或团队可以复用示范包的接口，独立改进正式算法，平台保持同一套题和评分。
