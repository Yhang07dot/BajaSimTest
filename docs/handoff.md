# 后续会话任务交接

## 本次范围决定

- 当前目标是让团队在稳定的Gazebo环境中接入感知算法、获取观测、与真值比较。
- 仿真真实性增强暂不考虑，现有模型保持；不把反射率、扫描畸变、照片级模型或悬架列入近期任务。
- 停车位当前只有基础模型/区域真值，没有评分，也没有停车控制。建议首轮验收暂缓；是否删除模型或扩展为边界突变测试尚未决定，不擅自删除。
- 本文供后续独立会话使用，本轮不启动这些开发任务。后续由用户指定会话领取任务，先读接口及评分规则。

## 开工前应确认的评分约定

1. 三维算法只检出障碍，还是还要求box/barrel/cone/person分类？当前分别提供objectness和semantic分数，不应混成总分。
2. 边界锥桶如何处理？当前不在障碍真值列表，预测成障碍可能计FP。建议增加明确ignore规则，或将边界锥桶纳入检测任务；选择后再改代码和测试。
3. 是否沿用1m中心距离、0.25置信度、前方30m、至少1返回点的基线门限？是否用IoU约束框质量？
4. 边线以0.5m内覆盖率和已覆盖点误差衡量，是否还限制冗余预测线段？
5. 二维与特殊路面输出和评分的最小交付范围是什么？这些原始需求仍未完成。
