# 设计记录

## 已确认约束

- Gazebo 提供真实传感器观测，算法由其他团队后续接入。
- 雷达名义离地 1.5m，角度导致地面近场盲区；不做 5m 硬截断。
- 环线加宽、边界左蓝右红、障碍适当增高。
- 随机障碍不阻挡固定轨迹车辆。
- 与随机物体真值比较评分；输入输出采用 ROS 消息。
- 示例简单，不默认录制大 rosbag。
- 仿真真实性增强暂缓，当前阶段聚焦接口、接入和可复算评分。

## 实现选择

独立工作空间采用一个 Python 平台包、一个接口包和一个 C++ 原生点云桥。场景生成时写出 SDF、本地 OBJ 网格和 JSON 真值；无需在线资源。碰撞和视觉使用相同路面网格，OBJ 明确写出顶点法线以兼容 DART 碰撞加载。原生桥避免 Gazebo Python transport 在解释器退出时的回调析构崩溃；Gazebo 进程退出先请求 server_control 服务，并提供有界的进程组清理。

车辆模板来自用户提供的 baja_cloud_sim-2.7，保留基本 Ackermann 物理机构，改为前视相机和修正后的 16×2000 雷达采样。控制只使用仿真位姿，不依赖待测感知。雷达桥接显式读取 XYZ float 字节，保留源时间戳并添加升序 ring，避免历史桥接字段类型问题。

随机障碍安全性采用占地外接圆到整个路径的距离，并对路径离散误差做保守修正；因此不只看物体中心是否在道路两侧。测试另用更密路径采样检查。

## 参数来源

- [C16 厂家规格书](https://www.leishenlidar.com/wp-content/uploads/2020/12/CX16-specification.pdf)：16 线、常见±15°、2°线间隔；具体版本可能有不同垂直分布。
- [C16 厂家产品页](https://leishen-lidar.com/en/cx/103)：单回波 320,000 pts/s，10Hz 约0.18°水平间隔。
- [SDF sensor specification](https://sdformat.org/spec/1.11/sensor/)：scan resolution 是采样倍率，不是角度值。本项目水平、竖直倍率均为1。
- [Gazebo ROS 2 integration](https://gazebosim.org/docs/harmonic/ros2_integration/)：使用 ROS/Gazebo 消息桥接。

5.6m 平地首次落点由 1.5/tan(15°) 推算，不是厂家标称最小量程。地形、车身姿态和物体高度均会改变实际可观测范围。
