# 评分依据

三维检出分与边线几何分各为0至100分，语义分类单独报告。没有加权总分。题目对象与输出要求分别见 [tasks.md](tasks.md)、[interfaces.md](interfaces.md)。评分器为 [evaluation.py](../src/baja_perception_sim/baja_perception_sim/evaluation.py)。

## 默认评测配置

配置文件：[scenario.yaml](../src/baja_perception_sim/config/scenario.yaml)。同一比较必须固定配置、场景、seed和速度，门限修改后应重新评测。

| 参数 | 默认值 | 含义 |
|---|---|---|
| confidence_threshold | 0.25 | 参与评分的最低预测置信度 |
| min_forward | 2m | 前方ROI起点 |
| max_distance | 30m | 最大水平距离 |
| half_fov_deg | 75度 | 三维目标中心的水平偏角上限 |
| min_lidar_hits | 1 | 真目标的最低有效激光返回数 |
| match_distance | 1m | 三维中心匹配门限 |
| boundary_obstacle_band | 0.25m | 道路边界背景带宽度 |
| boundary_tolerance | 0.5m | 同侧边线几何匹配容差 |
| boundary_sample_step | 0.5m | 边线弧长采样间隔 |
| result_timeout | 2s | 结果等待时间，使用仿真时间 |

## 三维目标：有效真值

生成场景保存物体真实类别、中心和尺寸，平台用点云采集时刻的车辆位姿将其变换到base_link。

真目标须满足中心x>=2m、水平距离<=30m、偏角绝对值<=75度，并且其真值框内至少有1个有效激光返回点，含3.5cm数值余量。此资格由框内返回点近似判断，不是精确分割标签。未达到返回点条件的真实ROI目标不计入召回分母；对应预测可被忽略。

随机目标锥桶是正目标，路边蓝红边界锥桶是背景。预测框中心位于道路真值边界水平距离0.25m内时先计FP，不允许借1m门限匹配附近目标。该背景规则优先于不可见目标忽略规则。当前默认场景的目标生成余量使真实目标中心位于背景带外；不应把背景带加宽到覆盖正目标。

只有规定ROI内、置信度达到门限的预测参与计分。

## 三维目标：匹配与得分

其余预测按三维中心距离<=1m与有效真值一对一匹配；优先保证最大匹配数量，再最小化距离。单个真值不能对应多个正确预测。

- TP：匹配成功的目标。
- FP：边界锥桶误报、地面/空处误报、其他未匹配预测和重复框。
- FN：没有匹配预测的有效真目标。

```text
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
F1分      = 100 × 2TP / (2TP + FP + FN)
```

objectness只评价检出，不要求类别相同。semantic同时要求类别正确；错分类产生对应预测类别FP与真实类别FN。unknown_obstacle可以获得检出分，不能作为语义类别正确。

误检/漏检扣分是上述F1的分解，不额外重复减分：

```text
误检扣分 = 100 × FP / (2TP + FP + FN)
漏检扣分 = 100 × FN / (2TP + FP + FN)
最终分   = 100 - 误检扣分 - 漏检扣分
```

例如10个目标全检出，无误报为100分；多报1个路边锥桶，TP=10、FP=1、FN=0，得95.24分，误检扣4.76分。若10个真目标输出9框，8个匹配成功，则TP=8、FP=1、FN=2，得84.21分。

TP/FP/FN按帧累计后计算分数，不是每个误报每帧固定扣5分。分母为零时为null，不解释为满分。

## 边线：双向几何评分

边线不要求逐个锥桶检测，只比较左右边界位置：

1. 按采集时间戳配对，同侧比较；ROI为x>=2m、水平距离<=30m，不使用三维目标的偏角裁剪。
2. 裁剪有限折线，不向端点外推，不跨多段空隙连线。
3. 真值线和预测线各按弧长约每0.5m均匀采样，输出点密度本身不改变成绩。
4. 预测采样点到同侧真值线距离<=0.5m的比例为precision；真值采样点到同侧预测线距离<=0.5m的比例为recall/覆盖率。
5. 几何F1=2PR/(P+R)，边线分=100×几何F1。汇总全部有效帧、左右两侧的采样计数后计算，不平均逐帧分数。

漏画降低recall，多画错误线段降低precision，左右颠倒不能匹配另一侧。有真值而输出为空时为0分，双方都空时为null。另报已覆盖真值点平均水平距离，需要与覆盖率一起阅读。

同一侧重合线段应合并后输出。当前采样实现未对重合线段去重，禁止重复堆叠线段改变权重；这类重复未设置独立扣罚。

边线分不评价高度、锥桶颜色或数量。锥桶误报扣三维分，不连带再扣边线分。

## 时间与结果统计

两项任务分别从首次合法输出开始激活。每个源帧等待最多2秒仿真时间，超时没有结果按空数组计分并记缺帧。真值消息不完整时跳过并单独统计，不记为算法漏检。算法未提交结果时显示等待，不是满分。

三维中心/尺寸误差和延迟保留最近最多100000样本；目标计数、边线采样计数和边线平均误差为本次运行累计。延迟使用仿真时间，不等同于CPU墙钟处理耗时。

框尺寸平均绝对误差另报；框朝向和IoU不决定当前中心匹配，AP未计算。当前成绩衡量本题规定的检出与几何估计，不直接证明完整框质量或实车部署能力。

## 查看与字段

执行 `./score.sh`，或查看EVALUATION RViz的LIVE SCORE、ROS `/evaluation/summary`、`<run-dir>/results/summary.json`。

JSON schema_version=2：objectness和semantic含tp/fp/fn、precision/recall/f1、score_100及两项扣分分解；boundary含precision/recall/f1、score_100、tolerance_m、mean_error_on_covered_points_m。还报告缺帧、不合法消息、真值不完整跳过帧和边界背景带误检数。

短rosbag录制只用于输入兼容性测试，没有配套真值时不能完成离线评分。
