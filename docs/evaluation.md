# 两项任务评分规则 v0.2

本轮任务是三维目标检测和道路边线几何估计，见 [tasks.md](tasks.md)。停车位已删除；二维图像和特殊路面区域不评分。真实性增强暂缓。

当前代码已实现以下规则；数值门限可在scenario.yaml中配置，正式验收前可共同调整。不提供未经约定的加权总分。JSON报告schema_version=2，输出消息字段保持兼容。

查看：`./score.sh`、EVALUATION RViz的LIVE SCORE、`generated/current/results/summary.json`、ROS `/evaluation/summary`。

## 三维检测：真值与匹配

真值来自生成场景保存的物体类别、中心和尺寸，按点云采集时刻的车辆位姿变换到base_link。默认评测框中心x>=2m、水平距离<=30m、偏角<=75度，且真值框内至少有1个激光返回点的物体；包含3.5cm数值余量。这是当前可观测性近似，不是独立相机可见性模型。

随机目标锥桶属于目标，路边蓝红边界锥桶属于背景。预测框中心落在真实边界水平距离0.25m内的背景带，先计FP，不允许借1m中心门限匹配附近真目标；随机目标生成的边缘余量保证当前默认配置下其中心不在该带中。后台使用真值划定此带，算法不能读取它来过滤预测。

其余置信度>=0.25的ROI内预测，与有效真值按三维中心距离<=1m一对一匹配；先最大化匹配数量，再最小化距离。重复框不能重复得分。无激光返回的真实ROI目标对应预测仍可忽略；边界背景带优先，不能被此忽略规则豁免。ROI外结果不计分。

- TP：正确匹配的障碍。
- FP：边界锥桶误报、地面/空处误报、未匹配预测和重复框。
- FN：未检出的有效真目标。

objectness只看障碍是否检出，不要求语义类别正确。semantic要求匹配并且类别一致；分类错误形成对应类别的FP和FN。仅几何算法可输出unknown_obstacle，比较objectness而不是要求其分类满分。

## 三维检测：误检如何扣分

```text
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
F1分      = 100 × 2TP / (2TP + FP + FN)
```

扣分不是额外随意减5分，而是同一F1公式的分解：

```text
误检扣分 = 100 × FP / (2TP + FP + FN)
漏检扣分 = 100 × FN / (2TP + FP + FN)
最终分   = 100 - 误检扣分 - 漏检扣分
```

分母为零时不评分，输出null。终端显示两种扣分，**不能再从F1分重复减一次**。按每帧累积TP/FP/FN后计算，避免每个锥桶每帧固定扣分导致轻易扣到负数。

例如10个目标全部检出，无误报为100分；再把1个路边锥桶报成障碍，则TP=10、FP=1、FN=0，得95.24分，误检扣4.76分。若10个目标输出9框、8个匹配，则TP=8、FP=1、FN=2，得84.21分。

框尺寸误差另报，当前朝向和IoU不决定匹配。检出分不等于框质量总评，也没有AP或额外类别加权。

## 边线：只比较几何

不需要锥桶检测列表，不按识别锥桶数量打分。对同一时间戳、同侧的真值线和预测线：

1. 裁剪到x>=2m、水平距离<=30m的共同ROI；不外推到折线两端之外，不跨多段空隙连线。
2. 分别沿弧长每约0.5m均匀采样，避免用密集输出点改变权重。
3. 预测采样点到同侧真值线<=0.5m的比例为precision；表示画出的线有多准确。
4. 真值采样点到同侧预测线<=0.5m的比例为recall/覆盖率；表示边界覆盖了多少。
5. 几何F1=2PR/(P+R)，边线分=100×几何F1；另报已覆盖真值点的平均水平距离。

漏画降低recall，多画远离道路的错误线段降低precision，左右颠倒不会匹配另一侧。空输出而存在真值时得0分；真值和输出都空时为null。只复制完全重叠的正确线段不会提高成绩，目前未单独处罚这类重复。

只评价水平几何，不评价锥桶颜色、数量或边线高度精度。所有三维与边线分数分开报告，误报锥桶扣三维检测分，不连带再扣边线分。

## 时间、缺帧与配置

两题均要求原始雷达采集时间戳和base_link。首次收到各自合法输出后激活对应任务；2秒仿真时间内没有结果按空数组计分并记缺帧。真值消息不完整时跳过并单独统计，不把平台真值缺失记成算法漏检。

误差/延迟保留最近最多100000样本，TP/FP/FN及边线采样计数为本次运行累计。仿真时间延迟不代表真实CPU墙钟耗时。

配置项：confidence_threshold、match_distance、min_lidar_hits、max_distance、min_forward、half_fov_deg、result_timeout；边线使用boundary_tolerance、boundary_sample_step；边界背景带使用boundary_obstacle_band。背景带不宜增大到覆盖真实目标中心。

报告v2边线字段为precision、recall、f1、score_100、tolerance_m、mean_error_on_covered_points_m；旧coverage_within_0_5m由recall替代。三维新增false_positive_penalty_100、false_negative_penalty_100，均为F1扣分分解。
