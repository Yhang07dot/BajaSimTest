# 评测规则 v0.1

评测默认针对瞬时 LiDAR 帧。配置和随机 seed 保存在 scene.json；帧真值由车辆位姿插值到点云时间戳获得。无算法时状态为 waiting_for_algorithm，不给虚假的满分。

本文描述当前代码实际执行的**基线规则**，数值门限尚待与算法团队确定为正式验收协议。当前没有覆盖三维、二维、路面等全部任务的综合总分，不能将某一项F1分数称作平台总准确率。

查看方法：根目录 `./score.sh` 实时终端评分；EVALUATION RViz 的 LIVE SCORE 文字；`generated/current/results/summary.json`；或 ROS `/evaluation/summary`。无真值 DEBUG RViz 专用于调试观测和算法结果，不显示评分真值。

## 目标资格

随机障碍与交通设施为独立目标。边界锥桶及停车位围栏用于边线/区域测试，不计入障碍类别的真值列表。

**待确认的公平性问题**：目前没有针对边界锥桶/停车位围栏的ignore标签，算法若将它们输出为障碍框，未匹配预测仍可能计FP。“不计入真值列表”不等于“自动忽略相应预测”。正式比较前应决定纳入目标、明确排除的输出范围，或实现ignore规则；建议优先解决这一项。

默认 ROI：框中心在车前 x>=2m，水平距离<=30m，水平偏角不超过±75°。属于 ROI 且其三维真值框内存在至少 1 个原始有效雷达返回点（含 3.5cm 数值余量）的目标才计入当前帧召回分母。这一定义考虑真实渲染的遮挡与线束稀疏，但不是精确像素分割：框内背景点或自车点可能造成资格误判，小目标也可能只有 1 点。后续可增加最低返回点数并对比其影响。

ROI 内的所有真实目标发布到 `/ground_truth/roi_objects`；有返回的子集发布到 `/ground_truth/eligible_objects`。两者都以原始采集时间戳、base_link 发布。算法不应读取这些话题。

## 匹配与分数

置信度>=0.25 的输出参与评分。对 ROI 内预测与有效真值用三维中心距离（默认<=1m）匹配，优先保证最多的一对一匹配，再最小化距离。此版本不使用 IoU，因此是粗粒度的定位与检出测试。

- objectness：只看是否检出真实障碍，不要求类别相同。
- semantic：正确匹配且类别相同才为 TP。分类错误同时形成预测类别 FP 和真实类别 FN。
- 未匹配预测为 FP，未匹配有效真值为 FN；重复框只允许一个成为 TP。
- 与无雷达返回的真实 ROI 目标匹配的预测忽略，避免惩罚融合算法检测到雷达不可见的物体。
- ROI 外预测不评价。

Precision=TP/(TP+FP)，Recall=TP/(TP+FN)，F1=2TP/(2TP+FP+FN)。分别报告 objectness、semantic 和每类结果；score_100=100×F1。分母为零时值为 null，不能解释成 100 分。

中心误差和框尺寸平均绝对误差在已匹配目标上计算。误差与延迟统计保留最近最多 100,000 样本；TP/FP/FN 为整次运行累计。当前没有 AP、IoU 或融合任务总分。

框尺寸和朝向不决定当前中心距离匹配是否成功；尺寸误差另行报告，朝向误差尚未计分。因此仅看F1不能证明包围框质量合格。

例如某帧有10个有效真值，算法输出9个框，其中8个匹配成功、1个误检、2个漏检，则Precision=8/9、Recall=8/10，F1=16/19，检出分约84.2。若8个匹配中只有7个类别正确，分类TP=7、FP=2、FN=3，分类分约73.7。两项没有再加权成总分。

边线单独报告覆盖率和误差，不混入目标F1。停车位没有专用评分，现有围栏只影响实际传感器观测；是否作为后续边界外凸/可行驶区域测试另行决定。

## 缺帧和延迟

第一次合法检测消息开始激活障碍评分。每个输入参考帧等待最多 2 秒**仿真时间**，没有输出时按空结果计分并增加 missing_frames。空数组属于正常输出，不算缺帧。不合法消息拒绝；过期、未来或错时间戳结果不会被强行对齐到其他帧。仿真暂停期间超时计时暂停。

延迟为接收时仿真时间减源时间戳，不代表真实 CPU 墙钟处理耗时。真实算法性能评测还需额外记录墙钟时延和实时因子。

## 边界

按相同源时间戳比较左右边界。真值采样点到同侧预测有限折线的最短水平距离<=0.5m 视为已覆盖。报告覆盖率，以及已覆盖点平均距离；二者需一起阅读。预测缺段或空数组对应零覆盖，不外推折线。收到首条合法边线输出后激活该项评分，此后缺帧计零覆盖。完全没有边线算法时保持 waiting_for_algorithm；边界冗余预测长度尚未单独罚分。

## 当前边界

仅适用于本场景几何、采样和规定 ROI 的算法比较，不能替代实车精度结论。当前未实现独立相机可见性、二维框、特殊路面区域、跟踪和交通状态切换评分。地形存在物理接触，但车辆没有经实车标定的悬架与轮胎模型。

真实性增强按用户要求暂缓，不列入近期任务。后续会话顺序与交付条件见 [handoff.md](handoff.md)。
